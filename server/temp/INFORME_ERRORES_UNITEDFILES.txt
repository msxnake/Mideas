ERROR CRÍTICO: ORG #4000 DESPUÉS DEL CÓDIGO
-----------------------------------------------
Línea 41: ORG #4000                ; Konami cartridge standard address

DESCRIPCIÓN:
- El archivo define el header del cartucho (líneas 13-15) ANTES de especificar ORG #4000
- Esto causa que el header se compile en dirección de memoria incorrecta
- En MSX, el header debe estar exactamente en #4000 para ser reconocido como cartucho válido

ESTRUCTURA ACTUAL (INCORRECTA):
```
DB "AB"              ; ROM signature    <- En dirección desconocida
DW INIT_KONAMI       ; Init address     <- En dirección desconocida
DW 0,0,0,0,0         ; Statement, ...   <- En dirección desconocida
[... código ...]
ORG #4000            ; <- ¡DEMASIADO TARDE!
```

ESTRUCTURA CORRECTA DEBERÍA SER:
```
ORG #4000            ; <- DEBE SER LO PRIMERO
DB "AB"              ; ROM signature    <- Ahora en #4000
DW INIT_KONAMI       ; Init address     <- Ahora en #4002
DW 0,0,0,0,0         ; Statement, ...   <- Ahora en #4004-#400C
```

  DW 0
  DW 0
  DW 0
  DW 0
  DW 0
