INSTALLATION
------------
1. Open terminal/command prompt
2. Navigate to project folder:
   cd C:\Users\salam\Documents\Programacion\Mideas\pygame_games\pacman

3. Install Pygame:
   pip install pygame

RUN THE GAME
------------
   python main.py

CONTROLS
--------
   Arrow Keys / WASD  - Move Pacman
   ENTER              - Start game
   ESC / P            - Pause
   Close Window       - Exit game

WHAT TO EXPECT
--------------
1. Game window opens (768x576 pixels)
2. Main menu shows "PACMAN" title
3. Press ENTER to start
4. Yellow Pacman appears in center
5. Move with arrow keys or WASD
6. Pacman animates (mouth opens/closes)
7. Press ESC to pause

TROUBLESHOOTING
---------------
Q: Game won't start?
A: Make sure pygame is installed: pip install pygame

Q: Window is too small/large?
A: Edit config.py, change SCALE value (default: 3)

Q: Sprites not showing?
A: Check assets.py loaded correctly (should see "Loaded 1 sprites")

Q: Slow performance?
A: Check FPS display, should be 60. Lower SCALE if needed.
