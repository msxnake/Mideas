## Branca
`millora_visual` — ja creada i activada. Canvis només a `components/editors/Msx2BitmapTileEditor.tsx` (l'editor de tiles de MSX2 Screen 5 bitmap).

## Problema actual
Al `Msx2BitmapTileEditor.tsx` (header, línies 1171–1245):
- Els botons de **rotate/mirror** (4 botons amb icona + text "Rotate left/right", "Mirror horizontal/vertical") estan barrejats al header dret amb Undo/Redo, Zoom i Grid. Amb `flex-wrap`, es trenquen malament i ocupen molt espai.
- Els controls de **shift/translate** ("Move pattern (wrap)") estan enterrats en un `CollapsiblePanel` del sidebar esquerra (línies 1147–1160), desconnectats visualment de rotate/mirror — quan conceptualment són el mateix grup de "transformacions".

Resultat: controls de transformació escampats i inconsistents, aspecte poc professional.

## Solució dissenyada
Crear una **toolbar horitzontal dedicada "Transforms"** just sota el header d'informació i sobre el canvas, amb botons **només d'icona + Tooltip** (estil Aseprite/professional), agrupant rotate + mirror + shift en un únic fil coherent amb separadors visuals.

### Layout resultant
```
┌──────────── Canvas header (info) ───────────────┐
│ [nom] 16x16 FG·BG   [↶][↷] [-8px+] [▦ Grid]   │  ← Undo/Redo+Zoom+Grid queden aquí
├──── Transforms (NOU) ───────────────────────────┤
│  ⟲ ⟳  │  ⇋ ⇅  │  ↑ ↓ ← →                       │  ← rotate | mirror | shift
├─────────────────────────────────────────────────┤
│              [ pixel canvas ]                    │
└──────────────────────────────────────────────────┘
```

### Detalls d'implementació

**1. Nova toolbar "Transforms"** (s'insereix entre línia 1245 i 1246, abans del `<div className="min-h-0 flex-1 overflow-auto...">` del canvas):
- Un `<div className="flex items-center gap-3 px-2 py-1 border-b border-msx-border bg-msx-panelbg/50">`.
- Tres grups de botons, separats per dividers verticals `<div className="h-5 w-px bg-msx-border" />`:
  - **Rotate**: `RotateCcwIcon` (rotate counterclockwise), `RotateCwIcon` (rotate clockwise)
  - **Mirror**: `FlipHorizontalIcon`, `FlipVerticalIcon`
  - **Shift**: `ArrowUpIcon`, `ArrowDownIcon`, `ArrowLeftIcon`, `ArrowRightIcon` (en fila plana)
- Cada botó: icona només amb `className="w-4 h-4"`, mida còmoda (`h-8 w-8 flex items-center justify-center rounded`), estil idle `text-msx-textsecondary hover:bg-msx-border hover:text-msx-textprimary`, transició suau.
- **Tooltips**: cada botó embolcallat amb el component `Tooltip` existent (`components/common/Tooltip.tsx`) amb `position="bottom"` i text clar en català/castellà ("Rotar 90° a l'esquerra", etc.). Això substitueix els `title=` nadius i dóna un aspecte molt més professional amb l'animació `fadeIn` que ja té el component.
- Una etiqueta discreta "Transforms" a l'esquerra (`text-[0.65rem] uppercase tracking-wide text-msx-textsecondary`) per donar context, seguint el patró d'apps pro.

**2. Neteja del header** (línies 1198–1237): elimino els 4 botons rotate/mirror del header. Hi deixen Undo/Redo (1196–1197) i Zoom + Grid (1238–1244), de manera que el header queda net i només conté info + accions globals d'edició/vista.

**3. Eliminació del CollapsiblePanel "Move pattern"** (línies 1147–1160): com que shift ara viu a la toolbar de Transforms, elimino aquest panell del sidebar.

**4. Neteja d'estat**: elimino `const [openMove, setOpenMove] = useState(false)` (línia 278), que ja no s'usa.

**5. Imports**: els icons `RotateCcwIcon`, `RotateCwIcon`, `FlipHorizontalIcon`, `FlipVerticalIcon`, `ArrowUp/Down/Left/RightIcon` ja estan importats (línies 13–16, 26–27, 36–37) i es mantenen — només canvien de lloc del header a la nova toolbar. **Afegeixo** `import { Tooltip } from '../common/Tooltip';`.
